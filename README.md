**CredentialChain 🔗🎓**

CredentialChain is a simple blockchain-based credential verification system built with Solidity, Ethers.js, and HTML/JavaScript.
It allows institutions to issue academic credentials on the blockchain and enables anyone to verify those credentials securely using a matriculation number.

**🚀 Features**

Issue student credentials on the blockchain

Verify credentials using matric number

Prevents fake or duplicate credentials

Uses MetaMask for blockchain interaction

Simple and user-friendly interface

**🛠️ Technologies Used**

Solidity – Smart contract development

Ethereum (Testnet) – Blockchain network

Ethers.js – Blockchain interaction

HTML, CSS, JavaScript – Frontend

MetaMask – Wallet & transaction signing


***⚙️ How to Run the Project***

Install MetaMask browser extension

Connect MetaMask to the same network used to deploy the contract

Open the project using Live Server or any local server (HTTP, not file://)

Click Issue Credential to store data on the blockchain

Click Verify Credential to confirm authenticity

✅ Notes

Ensure MetaMask is installed and enabled

Issuing and verification must be done on the same network

***Matric numbers are case-sensitive***
